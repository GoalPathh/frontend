# GoalPath Landing Page

Landing page Next.js hasil konversi dari referensi Stitch.

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Struktur

```txt
app/
components/
  landing/
  ui/
lib/
```

## Catatan

- Kode sudah dipecah per section agar clean dan mudah dipindahkan ke project utama.
- Styling menggunakan Tailwind CSS dan design token di `app/globals.css`.
- Icon menggunakan `lucide-react`, bukan Material Symbols CDN.
- Layout sudah dibuat responsive untuk mobile, tablet, dan desktop.
